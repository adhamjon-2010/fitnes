# 🏋️ Smart Fitness & Tana Diagnostikasi

Zamonaviy va qulay, shaxsiy fitness va tana tahlili veb-ilovasi.

## 🌐 Onlayn Havolalar (Jonli Sayt):
- **Vercel Havolasi:** [https://fitnes-wheat-two.vercel.app](https://fitnes-wheat-two.vercel.app)
- **GitHub Pages Havolasi:** [https://adhamjon-2010.github.io/fitnes/](https://adhamjon-2010.github.io/fitnes/)

Har qanday mobil telefon, planshet yoki kompyuter brauzeri (Chrome, Safari, Samsung Internet, Opera) orqali to'liq ishlaydi.

## 📱 Imkoniyatlar:
- Foydalanuvchi ismi va yoshini kiritish
- BMI (Tana vazn indeksi) va ideal vazn hisobi
- BMR (Asosiy metabolizm) va TDEE (Kunlik kaloriya sarfi)
- BJU (Oqsil, yog', uglevod) balansi
- Optimal suv me'yori kalkulyatori
- Haftalik reja va shaxsiy tavsiyalar
- Dark / Light mode (Tun / Kun rejimi)
- Maxfiy himoyalangan Admin Panel (statistika, foydalanuvchilar jurnali, CSV export)
